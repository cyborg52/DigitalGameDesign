Created custom assets for every graphic and sound in the game except for the font.
Removed old enemies and created 3 custom enemies:

Kelp snake travels either horizontally or vertically.
Seahorse travels in an L shape like the knight in chess. The red one turns right; the blue one turns left.
Squid travels in a straight line in any orientation. When the player (or other squids) get close, it squirts ink covering the screen.

Instead of the score counting up, coins spawn over time and give you the number on their face. Coins lose value and eventually disappear if not collected.
Increased the visual area while maintaining the play area so you can see enemies coming and they won’t kill you the moment you spawn.
